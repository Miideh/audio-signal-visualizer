# Audio Signal Visualizer

## Overview

The Audio Signal Visualizer is a Digital Signal Processing (DSP) foundation project exploring how real-world signals become digital data that can be processed by AI systems.

The project starts with signal generation and sampling experiments before progressing toward real-time audio analysis using Fourier Transform techniques.

## Engineering Focus

- Digital Signal Processing
- Signal representation
- Sampling
- Frequency analysis
- Fourier Transform
- Real-time visualization
- AI systems foundations
